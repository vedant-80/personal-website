# Design roadmap

1. Establish the permanent black/gray/white/wine red palette and global typography.
2. Replace text navigation with a centered accessible icon dock. Add `/projects` and preserve the existing `/professional` URL.
3. Build an immediate hero with oversized bold typography, concise introduction, and a three-photo composition. Apply reversible photo color treatment in CSS.
4. Add decorative animated contours and a cursor glow. Keep both behind content and accommodate touch and reduced-motion preferences.
5. Share flair color styling across public posts, filters, admin lists, and editing controls.
6. Replace remaining public page placeholder text without inventing project details.
7. Verify TypeScript, existing and updated tests, production build, route responses, and desktop/mobile presentation where browser tooling is available.

Follow-up content: actual project descriptions/links and a more personal biography can replace the deliberately brief introductory copy when supplied.
